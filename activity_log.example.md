# Intern activity log

Append what you worked on under a dated heading. The tool reads entries from the last
few days (see DRAFT_LOOKBACK_DAYS) and summarizes them into a LinkedIn draft. Write real
notes: the draft can only be as honest as what you put here.

Copy this file to activity_log.md and add your own entries. activity_log.md is gitignored
so your real notes stay off the public repo.
